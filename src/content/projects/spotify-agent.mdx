A powerful natural language agent that connects to Spotify through the Model Context Protocol (MCP). The project enables an LLM to control Spotify playback, manage playlists, and fetch music metadata using conversational prompts.

## Purpose

Built to explore tool-augmented LLM agents and demonstrate seamless control of real-world services using open protocols like MCP.

## Features

- Natural language control over Spotify
- Play, pause, skip tracks
- Playlist creation and management
- Song search and queue management
- Handles vague or ambiguous prompts gracefully

## Tech Stack

Model Context Protocol (MCP), Streamlit, Spotify-mcp-server, Google Gemini API, Agno Framework

## Team

Solo

## Learning Outcome

Learned how to securely integrate external APIs and real-world tools into LLM workflows using the MCP protocol. Deepened understanding of agent-based control and authentication flows.
