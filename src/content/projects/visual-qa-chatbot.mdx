A visual question answering system built using Gemini LLM and a multi-agent architecture. The system features two coordinated agents — one for image understanding and another for conversational Q&A — enabling users to upload an image, extract contextual information from it, and interact with a chatbot that responds based on the visual context.

---

## Features

- Vision-Language model integration using Gemini API
- Dual-agent setup for image processing and text-based interaction
- Real-time Q&A based on uploaded images
- Persistent chat memory with support for session resets
- Clean, responsive UI with TailwindCSS and React

---

## Tech Stack

- **Backend:** Python, FastAPI, Agno framework
- **Frontend:** React, JavaScript, TailwindCSS
- **LLM:** Gemini Vision Model (via API)

---

## Purpose

This project simulates a practical use case where users can interact with an image through natural language. It demonstrates how LLMs can be applied in real-world visual assistance and Q&A scenarios, making it suitable for portfolio, product prototypes, or assistive tech solutions.
