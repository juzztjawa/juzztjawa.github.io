Batch Norm Weakly supervised anomaly detection from surveillance videos using RGB and Flow features

By Jawahar A S on 15/5/2025
Python
Pytorch
scikit-learn

Modern surveillance systems generate hours of footage, yet catching rare abnormal events like thefts or fights remains a needle-in-a-haystack problem. Manual monitoring is exhausting and prone to errors. So, how do we build a system that automatically flags the suspicious moments — without needing frame-level labels?

This is the challenge tackled in my final year project: combining RGB and motion cues (optical flow) with a BatchNorm-driven learning framework to detect anomalies from surveillance videos — using only weak supervision.

🌟 The Problem

Traditional anomaly detection models use RGB features to learn what’s normal and what’s not. But this ignores something crucial: motion.

Subtle movement — like someone sneaking or sprinting — often signals an anomaly, and RGB frames alone won’t capture that.

Also, annotating the exact timing of anomalies is expensive and impractical. That’s where weak supervision comes in — we only know whether a full video contains an anomaly, not where.

The goal?

Build a system that understands “when something feels off”, even with coarse labels and minimal supervision.

🧠 Our Approach

We extend a state-of-the-art weakly supervised anomaly detection method by incorporating motion awareness through optical flow. Here’s how it all comes together:

🔍 Step 1: Extracting Features from Videos

Each video snippet (16 frames) goes through two parallel pipelines:

  • RGB Path: Passed through a frozen I3D model, giving a 1024-dim feature vector.
  • Flow Path: Optical flow is computed using RAFT-small, and then fed into another I3D model, producing another 1024-dim feature vector.

These are concatenated into a 2048-dimensional representation — capturing both appearance and motion.

✨ Step 2: Enhancing Features with Attention

Raw features can be noisy. To clean things up and focus on what matters, each stream passes through a Transformer-based Feature Enhancer. This module:

  • Captures short-term dependencies
  • Learns which parts of a video snippet are important
  • Outputs cleaner, more robust features

📈 Step 3: Scoring Snippets with DFM

We use a statistical measure called Divergence from Mean (DFM), which checks how much a feature vector deviates from the batch mean (via BatchNorm stats). High DFM scores? Likely anomalies.

This helps us choose which snippets to train on — we only use the most “suspicious-looking” ones.

🧲 Step 4: Mean-based Pull-Push Loss

Now comes the core of the training:

  • Pull normal features toward the batch mean
  • Push anomalous features away from the cluster

This is done using a custom Mean-based Pull-Push (MPP) loss, which doesn’t require explicit anomaly labels — it just uses statistical cues from the data.

[ \mathcal{L}{total} = \mathcal{L}{normality} + \lambda_1 \cdot \mathcal{L}{mpp1} + \lambda_2 \cdot \mathcal{L}{mpp2} ]

The result? A well-structured feature space that naturally separates normal and abnormal behavior.

🚀 Results that Matter

We tested the model on two benchmark datasets: UCF-Crime and XD-Violence.

📊 XD-Violence

  • RGB Only: 81.32% AP
  • RGB + Flow: 84.60% AP

📊 UCF-Crime

  • RGB Only: 80.95% AUC
  • RGB + Flow: 81.65% AUC

These gains are not just numerical — they show that motion cues make a real difference. The training was more stable, and the model could pick up on events that RGB alone missed.

📌 Key Insights

  • Motion-aware models outperform RGB-only ones in detecting subtle actions like fighting or fleeing.
  • The DFM + MPP framework structures the feature space elegantly, even under weak supervision.
  • Even with no frame-level labels, the system can localize anomalies well, purely by leveraging feature divergence.

🧭 Conclusion

This project demonstrates how a simple idea — combining motion and appearance — can drastically improve anomaly detection in videos. By integrating optical flow, leveraging BatchNorm statistics, and designing a clever loss function, we build a robust system that performs well with limited supervision.

But more than that, this work opens doors to future extensions:

  • Real-time inference (replace I3D with faster models like TimeSformer)
  • Better snippet selection strategies
  • Adapting the framework to online/streaming anomaly detection

Anomaly detection is a tough nut to crack, but this project takes a meaningful step forward — balancing accuracy, efficiency, and practicality in one cohesive system.
